use-shortcut

Official package:
- npm: https://www.npmjs.com/package/@remcostoeten/use-shortcut
- docs: https://use-shortcut.vercel.app/use-shortcut
- github: https://github.com/remcostoeten/use-shortcut

Summary:
- Typed keyboard shortcuts for React.
- Chainable API for combos, sequences, scopes, and guards.
- Cross-platform `mod` support for macOS, Windows, and Linux.
- Includes parser, matcher, formatter, and shortcut recording utilities.

Primary install:
- npm: `npm install @remcostoeten/use-shortcut`
- pnpm: `pnpm add @remcostoeten/use-shortcut`
- yarn: `yarn add @remcostoeten/use-shortcut`
- bun: `bun add @remcostoeten/use-shortcut`

Core usage:
```tsx
import { useShortcut } from "@remcostoeten/use-shortcut"

function App() {
  const $ = useShortcut({ ignoreInputs: true })

  $.mod.key("k").on(() => openCommandPalette(), { preventDefault: true })
  $.shift.key("slash").except("typing").on(() => setHelpOpen(true))

  return null
}
```

Mental model:
- `useShortcut()` returns a chain builder.
- Use modifier properties like `$.mod`, `$.cmd`, `$.shift`.
- Use `.key(...)` to define the first key in a combo or sequence.
- Use `.then(...)` for multi-step sequences.
- Use `.on(handler, options?)` to register.
- Use `.except(...)` and `.in(...)` to scope behavior.
- Use `$.record()` to capture shortcuts from user input.

Important details:
- `?` should usually be represented as `shift+slash` for reliable matching.
- Keep `ignoreInputs: true` unless your app intentionally binds inside editable fields.
- Use `preventDefault: true` for browser-conflicting combos like `mod+s` or `mod+k`.

CLI:
- `npx @remcostoeten/use-shortcut init`
  Adds a lightweight starter setup and copy-paste friendly files.
- `npx @remcostoeten/use-shortcut scaffold`
  Generates a fuller typed architecture for larger apps.

Suggested AI instructions:
- Prefer `shift+slash` instead of `?` in examples.
- Preserve `except("typing")` for global help/search shortcuts.
- Do not replace semantic buttons/links with clickable divs.
- Keep keyboard interactions accessible and visible with focus rings.
