# useShortcut Library Documentation

## Overview
`useShortcut` is a chainable, type-safe keyboard shortcut hook for React. It provides a fluent API for binding keys with support for cross-platform modifiers, exception handling (e.g., ignoring inputs), and comprehensive TypeScript support.

## Installation
```bash
npm install @remcostoeten/use-shortcut
# or
pnpm add @remcostoeten/use-shortcut
# or
bun add @remcostoeten/use-shortcut
```

## Basic Usage
```tsx
import { useShortcut } from "@remcostoeten/use-shortcut"

function App() {
  const $ = useShortcut()

  // Simple bind
  $.key("s").on(() => console.log("s pressed"))

  // With modifiers
  $.ctrl.key("s").on((e) => {
      e.preventDefault()
      save()
  })

  // Cross-platform 'mod' (Cmd on Mac, Ctrl on Win/Linux)
  $.mod.key("k").on(() => toggleSearch())
}
```

## API Reference

### 1. Initialization
#### `useShortcut(options?: UseShortcutOptions)`
Creates a shortcut builder instance attached to the component lifecycle.
- **options**:
  - `debug?: boolean`: Log events to console.
  - `delay?: number`: Global debounce/delay in ms.
  - `ignoreInputs?: boolean`: If true (default), ignores shortcuts when inside inputs/textareas/selects. Set `false` to allow.
  - `target?: HTMLElement | Window | null`: Target to attach listeners (default: window).
  - `eventType?: "keydown" | "keyup"`: Event to listen for (default: "keydown").
  - `disabled?: boolean`: Globally disable this builder instance.

### 2. Builder Chain
The builder uses a fluent syntax: `$.[modifiers].key(k).except(condition).on(handler)`

#### Modifiers
property accessors that toggle the modifier state.
- `.ctrl`
- `.shift`
- `.alt`
- `.cmd` (Meta key)
- `.mod` (Smart modifier: `cmd` on Mac, `ctrl` on Windows/Linux)

#### Methods
- **`.key(k: ActionKey)`**: Specifies the main key. Must be called before `.on()`.
  - `ActionKey` types include:
    - Alpha: `"a"-"z"`
    - Numeric: `"0"-"9"`
    - Function: `"f1"-"f12"`
    - Navigation: `"up", "down", "left", "right", "home", "end", "pageup", "pagedown"`
    - Special: `"enter", "escape", "space", "tab", "backspace", "delete"`
    - Symbol: `"slash", "minus", "plus", "equal", "comma", "period", "semicolon", "quote", "bracketleft", "bracketright", "backslash", "backtick"`

- **`.except(condition)`**: specific condition where the shortcut should NOT trigger.
  - **Presets (string)**:
    - `"input"`: Ignored in `<input>`, `<textarea>`, `<select>`.
    - `"editable"`: Ignored in `contentEditable` elements.
    - `"typing"`: Combined `"input"` + `"editable"`.
    - `"modal"`: Ignored if an element with `data-modal="true"` or `role="dialog"` exists.
    - `"disabled"`: Ignored on disabled elements.
  - **Function**: `(e: KeyboardEvent) => boolean`. Return `true` to skip handling.
  - **Array**: `ExceptPreset[]`

- **`.on(handler, options?)`**: Finalizes the binding.
  - **handler**: `(e: KeyboardEvent) => void`
  - **options**: `HandlerOptions`
    - `preventDefault?: boolean` (default: true for matched shortcuts)
    - `stopPropagation?: boolean`
    - `delay?: number` (execution delay)
    - `disabled?: boolean` (disable specific shortcut)
    - `description?: string`
    - `except?: ...` (override builder except)

- **`.handle(options)`**: Alternative to `.on` where handler is passed in options object.
  - `options`: `HandlerOptions & { handler: (e) => void }`

### 3. Return Object (`ShortcutResult`)
The `.on()` method returns a control object:
```ts
{
  unbind: () => void;       // Manually remove listener
  enable: () => void;       // Re-enable
  disable: () => void;      // Temporarily disable
  isEnabled: boolean;       // Current state
  display: string;          // Formatted string (e.g., "⌘K")
  combo: string;            // Internal ID (e.g., "cmd+k")
  trigger: () => void;      // Manually trigger handler
}
```

## Example Patterns

### Global Search (Command+K)
```tsx
$.mod.key("k")
  .on((e) => {
    e.preventDefault()
    setSearchOpen(true)
  })
```

### Save (Ctrl+S / Cmd+S)
```tsx
$.mod.key("s").on(saveDocument, {
  preventDefault: true,
  description: "Save changes"
})
```

### Navigation (Escape) outside inputs
```tsx
$.key("escape")
  .except("typing") // Don't close if user is typing text
  .on(closeModal)
```

### Complex Modifiers (Ctrl+Shift+F)
```tsx
$.ctrl.shift.key("f").on(enterFullscreen)
```

### Disabling shortcuts conditionally
```tsx
const saveShortcut = $.mod.key("s").on(save)

// later
saveShortcut.disable()
```
